# Relai v0.2

**Remember who matters.**

Relai is a mobile-first AI relationship-memory and event-networking prototype. It helps professionals capture contacts, preserve conversation context, discover relevant people, prepare event plans, share contact information, and save useful icebreakers.

## Run locally

Open `index.html` in a browser. No installation or build command is required.

## Deploy on Vercel

Import this repository into Vercel and select **Other** as the framework preset. Leave the build command and output directory empty; the app is already a complete static site at the repository root.
